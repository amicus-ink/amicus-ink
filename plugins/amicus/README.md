# AMICUS plugin for Claude Code and Codex

Audits a quantitative social-science paper against 14 methods checklists (iv, did, rdd,
conjoint, survey_exp, field_exp, text, matching, mediation, multilevel, panel, synth,
measurement, hte) and a universal checklist that runs on every paper, inside Claude Code or Codex. No Python and no clone needed.

## Install

```
/plugin marketplace add amicus-ink/amicus-ink
/plugin install amicus@amicus
```

## Use

```
/amicus path/to/paper.pdf [path/to/appendix.pdf]
```

The command routes the paper to the methods it uses, codes every check of each fired
checklist and of the universal checklist, and writes `AMICUS_REPORT.md` next to the paper: what the paper does well, the main
issues, then one table of every flag grouped into issues, with every check id listed. We run AMICUS with Claude Opus 5.5 in Claude Code; other models
work but their verdicts are not comparable.

If a bare `/amicus` is ambiguous in your setup, use the namespaced form `/amicus:amicus`.

## Codex

```
codex plugin marketplace add amicus-ink/amicus-ink
codex plugin add amicus@amicus
```

Then, in a Codex session in the paper's folder, ask: "Run AMICUS on paper.pdf".

## Other agents

`skills/amicus-audit/` is a plain [Agent Skills](https://agentskills.io) folder. Agents that read
that format, such as OpenCode, can use it directly: copy the folder into the agent's skills
folder (for OpenCode, `~/.agents/skills/` or a project's `.opencode/skills/`).

## Rebuilding

The files in `skills/amicus-audit/checklists/`, `IMPORTANCE_PROMPT.md` and `REPORT_GUIDE.md` are
generated by `scripts/build_claude_plugin.py` in the authors' internal repository (not published) from the same
shipping checklists and prompts as the claude.ai Skill. Do not edit them by hand.
