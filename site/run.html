Run it

So far there are two ways to run AMICUS: in an online chatbot, or with a coding agent on your own computer. Both use the same checklists, and your paper goes only to the model provider which you already use.

1. In an online chatbot

Claude, ChatGPT, Gemini or any other chatbot. Nothing to install.

Attach your paper, and any appendix, and write:

Run the checklist at https://amicus.ink/AMICUS.md. If a link fails to open, retry it and open each checklist link directly; do not stop after one error.

The chatbot reads that file, decides which methods your paper uses, opens only those checklists, and writes the report in the conversation. A long paper with several methods may take more than one reply. If your chatbot cannot open links, download AMICUS.md and the checklist for your method from the checklists page, and attach them instead.

2. With a coding agent on your computer

Claude Code, Codex or OpenCode. The report is saved as AMICUS_REPORT.md next to your paper.

Claude Code

/plugin marketplace add amicus-ink/amicus-ink
/plugin install amicus@amicus
/amicus draft.pdf appendix.pdf

If another plugin also has an /amicus command, type /amicus:amicus.

Codex

codex plugin marketplace add amicus-ink/amicus-ink
codex plugin add amicus@amicus

Then open Codex in your paper’s folder and ask it to “Run AMICUS on draft.pdf”.

OpenCode and other agents

Any agent that reads Agent Skills can use the same skill. Copy its folder into the agent’s skills folder, then ask the same thing:

git clone --depth 1 {{REPO_URL}} /tmp/amicus-ink
mkdir -p ~/.agents/skills && cp -R /tmp/amicus-ink/plugins/amicus/skills/amicus-audit ~/.agents/skills/

For the most consistent results: the Python script

The plugin works through the checklists in one session. The script instead reads each method in a separate call, checks every verdict against the checklist, and stops with a clear error if anything fails. It uses Claude Code or Codex, whichever you have installed and logged in, so it runs on your own subscription.

git clone {{REPO_URL}} amicus && cd amicus
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
python3 scripts/skillgen/paper_only_audit.py --paper draft.pdf --agent claude

Use --agent codex to run it with Codex instead. Add --modules did,panel to choose the methods yourself.

Which model?

Any capable model will do the reading. We run AMICUS with Claude Opus 5.5 in Claude Code and GPT-6.1 Sol, at high reasoning effort, in Codex. The results in our working paper use Claude Sonnet 5.5. In our comparison on 25 pairs of working papers and their published versions, Claude Sonnet 5.5 agreed with Opus on 90% of checks and GPT-6.1 Sol on 86%. GPT-6 Luna, a smaller model, agreed on 83%.
