What comes next

This is version 0.1. Here is what we are working on, roughly in order.

  1. Done

    Does it help?

    We audited 798 working papers and compared 406 of them with their later published versions. Sounder working papers were more likely to be published, and published versions score modestly higher. The results are in our paper.

  2. Next

    Running the analysis

    With a paper’s code and data, run the alternative specifications the checks call for, show which results are sensitive to them, and what best practice would change.

  3. Planned

    A version in your browser

    A page where you upload a paper and use your own API key, with nothing to install and nothing sent to us.

  4. Ongoing

    More methods

    More methods are being built. Each is added once it meets the same bar as the others.

Tell us what you need

Which method should come next? Did a reading help, or get something wrong? Open an issue on the repository; that is the best way to reach us.
